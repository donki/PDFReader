# Avisos de terceros — PDF Editor

| Componente | Uso | Licencia | Titular |
|---|---|---|---|
| .NET MAUI | Interfaz y plataforma (Android y Windows). | MIT | Microsoft |
| PDFsharp 6.2 | Escritura de PDF en las herramientas: fusionar, dividir, organizar páginas, imágenes a PDF, contraseñas, numeración y marca de agua. | MIT | empira Software GmbH — <https://github.com/empira/PDFsharp> |
| Open Sans | Tipografía de la interfaz y de las casillas de texto. | SIL Open Font License 1.1 | Steve Matteson / Google |
| Lora | Tipografía serif de las casillas de texto. | SIL Open Font License 1.1 | Cyreal |
| Roboto Mono | Tipografía monoespaciada de las casillas de texto. | Apache 2.0 | Google |
| Caveat | Tipografía manuscrita de las casillas de texto. | SIL Open Font License 1.1 | Impallari Type |

El renderizado de páginas es el nativo de cada plataforma (`android.graphics.pdf.PdfRenderer`,
`Windows.Data.Pdf`) y no supone ninguna dependencia de terceros.
